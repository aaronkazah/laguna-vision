Laguna Vision
A visual input path for poolside/Laguna-XS.2

Trained on a 300k-example general vision recipe from 13 public sources — the model learns to identify objects, read documents, parse charts, understand screenshots and UIs, and answer visual questions grounded in what it sees. Early — but the full pipeline is working end to end.

SigLIP so400m-384 (vision encoder) AnyRes global + 4 tiles (multi-scale) Resampler · 256 tokens (projector) LoRA r64 / a128 (parameter-efficient fine-tuning) vLLM serving (inference) 300k examples (documents, OCR, charts, screenshots, UIs, natural images)
Laguna Vision · model card 01 / 08
The limit

Laguna XS.2 is text-only.

For real computer use that is a hard wall. The state an agent needs lives in a screenshot, a browser page, a form, a chart, a terminal, or an error dialog — not in the prompt. Today a human has to transcribe it.

Without vision

Blind to the screen

  • No sensor for pixels
  • No learned bridge from pixels into the token stream
  • Guesses or refuses when the answer is on screen
Laguna Vision adds

The missing interface

  • Visual sensing over screenshots & documents
  • A token bridge into Laguna's embedding space
  • The backbone is adapted — not a captioner bolted on the side

Laguna Vision 03 / 08
Data recipe · general-vision-300k-v1

300k examples from 13 public sources

Stage 1 · Alignment · 120k

LLaVA-Pretrain-558k

  • BLIP captions over LAION / CC / SBU images
  • Teaches the projector to land visual features in Laguna's embedding space
  • Backbone stays frozen — only the resampler trains
Stage 2 · Instruction · 180k

12 diverse visual-QA sources

  • General perception — LLaVA-Instruct 65k + ShareGPT4V 35k (COCO train2017)
  • Compositional QA — GQA 25k (objects, attributes, spatial)
  • Documents & OCR — DocumentVQA 7k · TextVQA 7k · OCR-VQA 6k · ChartQA 5k
  • UI & screenshots — WebSight 10k · RICO-ScreenQA 7k · Screen2Words 4k · WebSRC 4k
  • Synthetic controls — Spatial-OCR 5k (positional grounding)

All sourced from HuggingFace Hub and public datasets. Every example is image + question + answer. The recipe, manifests, and download scripts are committed in lagunavision/data/.

Demo ideas

Text-only vs Vision, side by side

Drop a terminal screenshot with a stack trace and ask for the failing command and likely cause — state an agent usually needs a human to transcribe.

Ablation: blind / OCR / visual

Run eval-ablation live — blind-text vs OCR-only vs trained-visual vs untrained-control — to prove the visual tokens carry the signal, honestly.
